# Морський бій з ШІ-супротивником

Лабораторна робота 1 з предмету «Основи штучного інтелекту». Тема: гра з ШІ-супротивником.

Я реалізувала класичний морський бій 10×10 на Python з pygame. Гравець розставляє свій флот і б'ється проти комп'ютера. Є три рівні складності. Усі алгоритми я писала сама, без готових бібліотек для ШІ.

---

## Що є в проєкті

- `main.py` — точка входу.
- `battleship/board.py` — поле, кораблі, правила розстановки, постріли, «червона зона» навколо потопленого корабля.
- `battleship/knowledge.py` — що стрілець знає про поле суперника. Тільки це бачить ШІ.
- `battleship/ai.py` — базові класи ШІ та рівні Легкий і Середній, а також перша версія складного рівня (діагональна сітка), яку я лишила для порівняння.
- `battleship/ai_probability.py` — Складний рівень: ШІ на карті ймовірностей.
- `battleship/levels.py` — який клас ШІ відповідає якому рівню.
- `battleship/placement.py` — стратегія розстановки флоту («берегова лінія» і розпорошення).
- `battleship/game.py` — фази гри, ходи, перемога.
- `battleship/ui/` — графічний інтерфейс (pygame), розділений на модулі:
  - `app.py` — сцени (меню, розстановка, бій), керування, ігровий цикл, журнал і статистика;
  - `render.py` — малювання поля: вода, кораблі, полум'я, радар, приціл;
  - `ships_art.py` — малювання кораблів;
  - `effects.py` — вибухи, бризки, дим, феєрверк, тряска екрана;
  - `background.py` — анімований фон;
  - `sound.py` — звуки (створюються програмою, окремих файлів немає);
  - `widgets.py` — кнопки й панелі;
  - `theme.py` — розміри, кольори, шрифти.
- `assets/` — шрифти Russo One і PT Sans (з кирилицею) та іконка вікна.
- `simulate.py` — порівняння стратегій для звіту.
- `tests/` — автотести.
- `docs/ALGORITHMS.md` — як працюють алгоритми.
- `docs/INTERFACE.md` — як влаштований інтерфейс.

## Правила

Поле 10×10. Флот: 1 чотирипалубний, 2 трипалубні, 3 двопалубні, 4 однопалубні (усього 20 клітинок). Кораблі стоять прямо і не торкаються один одного, навіть кутами. Якщо влучив, стріляєш ще раз. Коли корабель потоплено, клітинки навколо нього автоматично стають промахами.

### Коли закінчується гра

- Гравець перемагає, якщо потопив усі 10 кораблів комп'ютера.
- Комп'ютер перемагає, якщо потопив усі 10 кораблів гравця.
- Нічиєї не буває: кожен постріл відкриває нову клітинку, а стріляти двічі в одну не можна, тому гра завжди закінчується.

## ШІ-супротивник

Морський бій це гра з неповною інформацією: кораблів суперника не видно. Тому minimax з α-β відсіканням тут не підходить (його можна було б зробити для гри, де видно все поле). Замість цього ШІ рахує, де кораблі найімовірніші, і стріляє туди.

### Рівні складності

| Рівень   | Як шукає кораблі                        | Добиває підбитий корабель |
|----------|------------------------------------------|---------------------------|
| Легкий   | стріляє у випадкові клітинки            | так                       |
| Середній | шахова парність (через одну клітинку)   | так                       |
| Складний | карта ймовірностей                      | так                       |

### Складний рівень (карта ймовірностей)

Для кожної клітинки ШІ рахує, скільки способів розмістити ще не потоплені кораблі проходить через неї. Клітинка з найбільшим числом і є найкращою ціллю.

1. Беремо кожен живий корабель за довжиною.
2. Перебираємо всі його можливі позиції (горизонтально і вертикально).
3. Позиція підходить, якщо не виходить за поле і не накриває промах чи потоплений корабель.
4. Кожна підходяща позиція додає +1 усім своїм клітинкам.
5. Стріляємо в невідкриту клітинку з найбільшим числом (якщо їх кілька, обираємо випадкову).

Якщо на полі є підбитий, але не потоплений корабель, ШІ переходить у режим добивання: враховуються тільки ті позиції, які повністю накривають групу влучань. Тому ШІ сам «здогадується» про напрямок корабля і стріляє вздовж нього.

Докладніше з прикладами і результатами порівняння: [docs/ALGORITHMS.md](docs/ALGORITHMS.md).

### Де це в коді

| Що                                           | Де                                            |
|----------------------------------------------|-----------------------------------------------|
| Карта ймовірностей                           | `ai_probability.py`: `probability_map`        |
| Режим добивання                              | `ai_probability.py`: `_consistent`            |
| Вибір клітинки для пострілу                  | `ai_probability.py`: `best_cells`, `choose`   |
| Середній рівень (шахова парність)            | `ai.py`: `MediumAI`, `grid_candidates`        |
| Добивання хрестом (Легкий і Середній)        | `ai.py`: `TargetingAI.target_cells`           |
| «Червона зона» після потоплення              | `board.py`: `receive_shot`; `knowledge.py`    |
| Яким класом грає який рівень                 | `levels.py`                                   |
| Розстановка: берегова лінія, розпорошення    | `placement.py`: `_try_smart`                  |

Комп'ютер розставляє свій флот за стратегією розстановки (великі кораблі вздовж краю, подалі один від одного). Гравець може зробити так само кнопкою «Рекомендована».

## Інтерфейс

- Меню з вибором рівня і анімованим фоном.
- Розстановка: корабель-«привид» під курсором (зелений можна, червоний не можна), список флоту з лічильником.
- Бій: снаряд летить до цілі, при промаху будуть бризки, при влученні вибух і вогонь, потоплений корабель обвуглюється і димить.
- Активне поле підсвічується, на полі ворога крутиться радар, а курсор перетворюється на приціл.
- Праворуч статистика (постріли, влучання, точність) і журнал ходів.
- Після гри підсумкова таблиця (при перемозі ще й феєрверк).
- Звукові ефекти.

## Керування

| Дія                                 | Клавіша або кнопка          |
|-------------------------------------|-----------------------------|
| Поставити корабель                  | ЛКМ по лівому полю          |
| Повернути корабель                  | ПКМ або `R`                 |
| Почати бій                          | кнопка «СТАРТ» або Enter    |
| Постріл                             | ЛКМ по правому полю         |
| Показати, куди збирається стріляти ШІ | `H` (Середній і Складний) |
| Нова гра                            | `N`                         |
| Звук увімкнути або вимкнути         | `M`                         |
| Повний екран                        | `F` або `F11`               |
| Меню або вихід                      | `Esc`                       |

Кнопка «План ШІ» (`H`) підсвічує клітинки, з яких ШІ зараз обирає постріл. Для Складного це клітинки з найбільшим числом на карті ймовірностей.

## Запуск (macOS, Apple Silicon)

```bash
cd battleship_project
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

Інші команди:

```bash
python simulate.py --games 1000 --seed 7
python -m unittest discover -s tests -t .
```
